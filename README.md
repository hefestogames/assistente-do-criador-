# 🎬 Assistente do Criador

Radar inteligente para descobrir canais dark que estão estourando no YouTube.

## ✨ Funcionalidades
- 🕵️ Caçador de canais por palavra-chave
- 🔎 Analisador de canal específico
- 💰 Estimativa de ganhos por vídeo
- 🧬 Vídeos-modelo para copiar

## 🚀 Como rodar
pip install -r requirements.txt
python app.py

100% gratuito.
